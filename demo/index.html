콘서트 티켓 예매

2026년 가을 단독 콘서트. 잠시 후 매진 예상.

로더가 자동으로 location.hostname(localhost)을 site 식별자로 사용합니다.

테스트 방법

  1. 관리자에서 localhost의 max_active 조정 → 관리자 열기
  2. 이 페이지를 여러개 띄우면 한도 초과시 대기 화면 표시
  3. 먼저 들어간 탭을 닫으면 다음 순번 자동 입장
  4. 문구도 관리자에서 실시간 변경 가능

다른 도메인 테스트

관리자에서 example.local 같은 새 사이트 추가 후, hosts 파일에 등록하면 별개의 큐로 동작.
